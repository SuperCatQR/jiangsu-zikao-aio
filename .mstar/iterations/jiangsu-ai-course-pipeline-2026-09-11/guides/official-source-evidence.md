## 二、教材计划区解析规则（T2 必须实现）

1. **区边界**：区起点 = 含表头 `教材代号` 的行；区终点 = 下一处表头或文档末尾。**只在此区内匹配**。
2. **版式归一化**：行可能跨行（课码独占一行、教材代号在相邻行），须先归一化再按 `^<code>\d{1,3}$` 匹配教材代号 token（后缀**不限于** `0` / `1`：实测含 `150400` / `047471` / `130031` / `131401` 等）。
3. **佐证要求**：命中行窗口内需含 `出版社` / `大学出版社` / `高纲` / `考试指导委员会` 之一。
4. **跨文档并集**：四份文档取并集（`04747` 命中第 1、3 份：`jiangsu-2025-04-07` / `jiangsu-2026-04-07`；`04751` / `00898` 命中第 2、4 份：`jiangsu-2025-10-2026-01` / `jiangsu-2026-10-2027-01`）。
5. **反例**：考试日程区出现的课码（如 `15040` 在 `.../document.extracted.md:70-168`）**不得**判为匹配。
