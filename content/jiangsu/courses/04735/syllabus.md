## 考纲概览

### 考试范围

04735 的考试范围围绕“数据库系统原理 + 关系数据库 + SQL + 设计 + 安全 + 应用开发”展开，正文覆盖八章：

| 章节 | 范围摘要 | 复习定位 |
| --- | --- | --- |
| 第一章 数据库系统概述 | 数据、数据库、DBMS、DBS，数据库管理技术发展，三级模式结构，数据模型 | 建立全课概念框架 |
| 第二章 关系数据库 | 关系数据结构、关系操作集合、完整性约束、规范化理论 | 后续 SQL、设计题与范式题基础 |
| 第三章 数据库设计 | 设计目标、内容、过程、基本步骤，E-R 模型与逻辑 / 物理设计 | 设计题主干 |
| 第四章 SQL 与关系数据库基本操作 | SQL 概述、MySQL 预备、DDL、DML、SELECT、视图 | 操作题与读写 SQL 核心 |
| 第五章 数据库编程 | 存储过程、存储函数及其创建、调用、删除 | SQL 编程题基础 |
| 第六章 数据库安全与保护 | 完整性约束、触发器、安全性与访问控制、事务与并发、备份恢复 | 综合应用与简答高频候选 |
| 第七章 数据库应用设计与开发实例 | 需求描述与分析、系统设计、系统实现、系统测试与维护 | 设计流程综合应用 |
| 第八章 数据管理技术的发展 | 第一 / 二 / 新一代数据库系统、数据仓库、数据挖掘、大数据管理技术 | 概念性与趋势性识记 |

### 考核目标层级

| 层级 | 说明 | 占比（约） |
| --- | --- | ---: |
| 识记（Ⅰ） | 识别并记忆数据库原理相关概念、定义、性质、分类、组成、过程、功能和作用等 | 20% |
| 领会（Ⅱ） | 理解数据库基本概念和原理的内涵、外延、适用条件，能够说明概念之间的区别与联系 | 30% |
| 简单应用（Ⅲ） | 基于已知数据库概念、基本原理和方法，分析和解决常规问题 | 30% |
| 综合应用（Ⅳ） | 综合运用数据库原理、方法和技术，分析或解决较复杂的应用问题 | 20% |

> 难度结构：大纲说明试题难度大致为易、较易、较难、难四级，比例约为 2:3:3:2。复习时应避免只背术语，需同时练习 SQL、E-R 建模、范式判断与并发控制场景分析。
