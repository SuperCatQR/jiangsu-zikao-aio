# 江苏自考课程页索引

本目录存放跨专业复用的共享课程页。每门课程按独立子目录组织（例如 `15044/index.md`），采用标准的“五页读者模型”。

!!! tip "课程资料五页读者模型"
    每门成熟课程均包含：**1. 课程概览 (index)** ｜ **2. 考纲与范围 (syllabus)** ｜ **3. 学习计划 (plan)** ｜ **4. 练习与真题 (practice)** ｜ **5. 来源与核验 (sources)**。

## 查询与使用方法

1. **按课程代码查询**：课程名称可能存在微调，全国及江苏统考一律以 **5 位课程代码** 为准。
2. **确认成熟度与状态**：查看课程的 `资料状态`（complete / metadata-only / needs-review）与 `成熟度`（green / yellow / red）。
3. **按读者路径复习**：从概览了解政策与学分 → 查考纲知识树 → 按周跟进计划 → 查真题索引与考点。
