# 江苏自考课程页索引

本目录存放跨专业复用的课程页。课程页统一使用目录形态，例如 `13000/index.md`。

## 如何使用

1. 先用课程代码定位课程；同名课程以代码为准。
2. 进入课程页后，优先看官方来源、资料状态和页面成熟度。
3. `metadata-only` / `missing-source` / `needs-review` 代表资料仍需核验；私有原件只通过 `materials://` 引用。

课程页优先记录：

1. 课程在江苏专业计划中的使用情况。
2. 当次考试教材与大纲来源。
3. 知识树、章节笔记、题型和真题索引。
4. AI 生成内容的人工审核状态。
