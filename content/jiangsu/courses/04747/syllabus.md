### 考试范围

本课程考查 Java 语言面向对象与跨平台两大特点下的基本原理、方法和应用技术。考纲明确**仅针对理论部分**，实践部分另作说明。考试范围覆盖考纲正文规定的考核章节（第 7、11、12、13 章**不作考核要求**）：

| 章节 | 内容 | 是否考核 |
| --- | --- | --- |
| 第 1 章 | 概述（Java 语言特点、应用背景、开发环境与工具） | 考核 |
| 第 2 章 | 标识符和数据类型（关键字、标识符、注释、基本数据类型、常量与变量、类型转换、面向对象基本概念） | 考核 |
| 第 3 章 | 表达式和流程控制语句（运算符、各类表达式、条件/循环语句、Math 类） | 考核 |
| 第 4 章 | 数组、向量和字符串（一维/多维数组、String、StringBuffer、数组工具类） | 考核 |
| 第 5 章 | 进一步讨论对象和类（类与对象、继承、接口、抽象类、包、访问控制、重载/覆盖） | 考核 |
| 第 6 章 | Java 语言中的异常（常见异常及处理、用户自定义异常） | 考核 |
| 第 7 章 | Java 语言的高级特性 | **不作考核要求** |
| 第 8 章 | Java 的图形用户界面设计（容器、布局管理、事件处理、AWT/Swing 组件） | 考核 |
| 第 9 章 | Swing 组件（标签、按钮、文本框、列表、组合框、菜单、对话框、辅助类） | 考核 |
| 第 10 章 | Java Applet（Applet 基础、生命周期、运行机制、与 HTML 配合） | 考核 |
| 第 11 章 | Java 数据流 | **不作考核要求** |
| 第 12 章 | 线程 | **不作考核要求** |
| 第 13 章 | Java 的网络功能 | **不作考核要求** |

课程重点（考纲 §Ⅰ.四 + 各章「本章重点」）：Java 语言的特点与开发环境的基本使用；常变量和面向对象基本概念；流程控制语句；数组的声明、创建和使用；**类与对象的创建和使用、类与类之间的关系（本课程学习重点）**；继承过程中产生的隐藏和覆盖问题（本课程难点）；异常处理机制；容器、布局与常规组件的基本使用、委托事件处理机制；常规组件的综合使用；Applet 类的主要方法和生命周期。

### 题型及分值比例

本课程考试方式为闭卷、笔试，满分 100 分，60 分及格，考试时间 150 分钟（考纲 §Ⅳ.七.5）。考纲对不同能力层次要求的分数比例明确公布（识记 20% / 领会 30% / 简单应用 30% / 综合应用 20%，考纲 §Ⅳ.七.2），难易程度比例为易∶较易∶较难∶难 = 2∶3∶3∶2（考纲 §Ⅳ.七.3）：

| 能力层次 | 分值比例 | 对应题型（参考） |
| --- | ---: | --- |
| 识记（Ⅰ） | 20% | 单项选择题、填空题为主 |
| 领会（Ⅱ） | 30% | 单项选择题、填空题、简答题 |
| 简单应用（Ⅲ） | 30% | 简答题、程序改错题、程序分析题 |
| 综合应用（Ⅳ） | 20% | 程序分析题、程序设计题为主 |

考纲 §Ⅳ.七.4 列明本课程考试**可能采用的题型**：单项选择题、填空题、简答题、程序改错题、程序分析题、程序设计题。

| 题型 | 来源 | 说明 |
| --- | --- | --- |
| 单项选择题 | 考纲 §Ⅳ.七.4 + 附录题型示例 | 四选一，考查概念识记与原理领会 |
| 填空题 | 考纲 §Ⅳ.七.4 + 附录题型示例 | 考查关键概念、术语、API 的准确记忆 |
| 简答题 | 考纲 §Ⅳ.七.4 + 附录题型示例 | 简述概念、机制、区别 |
| 程序改错题 | 考纲 §Ⅳ.七.4 + 附录题型示例 | 给出有错代码，指出错误行号并改正 |
| 程序分析题 | 考纲 §Ⅳ.七.4 + 附录题型示例 | 给出程序，写出运行结果 |
| 程序设计题 | 考纲 §Ⅳ.七.4 + 附录题型示例 | 按要求编写完整类/方法 |

### 考核目标层级

本课程考核目标按**四层制**（考纲 §Ⅱ），四个能力层次是递升关系，后者建立在前者基础上：

| 层级 | 说明 | 占比 |
| --- | --- | ---: |
| 识记（Ⅰ） | 识别和记忆有关知识点的主要内容（定义、术语、概念、方法等），并能正确表述、选择和判断 | 20% |
| 领会（Ⅱ） | 领悟和理解知识点的内涵与外延，熟悉内容要点及其区别和关系，能正确解释、说明和论述 | 30% |
| 简单应用（Ⅲ） | 运用课程知识点，解决一般的应用问题 | 30% |
| 综合应用（Ⅳ） | 运用课程方法，结合问题要求，设计程序，解决较为复杂的应用问题 | 20% |

> 注：占比直接援引考纲 §Ⅳ.七.2，非推算值。
