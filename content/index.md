## 状态与治理口径

| 维度 | 状态标识 | 含义说明 |
| :--- | :--- | :--- |
| **资料完整度** | <span class="zk-badge zk-badge-green">complete</span> | 官方大纲、教材信息、章节知识树及真题索引均已完整收录 |
| | <span class="zk-badge zk-badge-amber">metadata-only</span> | 仅收录官方课程代码、名称与基础元数据，待补章节大纲 |
| | <span class="zk-badge zk-badge-red">missing-source</span> | 缺失关键官方权威来源，需从考试院或高校补齐原始依据 |
| | <span class="zk-badge zk-badge-amber">needs-review</span> | 内容已生成或抽取，待人工审核确认后方可签发 |
| **页面成熟度** | <span class="zk-badge zk-badge-green">green</span> | 无阻塞性缺口，满足读者五页路径与核验标准 |
| | <span class="zk-badge zk-badge-amber">yellow</span> | 存在次要缺口（如缺部分考期题型或待人工签发），不阻断阅读 |
| | <span class="zk-badge zk-badge-red">red</span> | 存在核心要素缺失或错误，禁止作为最终备考依据 |

!!! note "数据安全与版权合规说明"
    本公开资料库严格执行“仅收录官方公开来源、索引与结构化摘要”政策。教材完整原件、扫描件及非公开题库一律隔离于私有仓并通过 `materials://` 方案引用，严禁在公开页面包含受版权保护的原始扫描件或题库全文。
