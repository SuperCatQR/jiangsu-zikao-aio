# 江苏自考资料库

公开仓只放**官方公开来源、索引、摘要**；教材原件、扫描件、非公开资料一律使用 `materials://` 私仓引用。

## 快速入口

| 入口 | 用途 |
| --- | --- |
| [江苏总览](jiangsu/index.md) | 省级政策、专业、课程入口 |
| [专业索引](jiangsu/majors/index.md) | 按专业进入考试计划与课程表 |
| [课程索引](jiangsu/courses/index.md) | 跨专业复用课程资料页 |
| [缺口雷达](jiangsu/gaps/index.md) | 查看缺教材、缺计划、待核验课程 |
| [内容标准](jiangsu/standards/index.md) | 公开内容、materials、课程页、发布闸门规则 |

## 状态口径

| 类型 | 枚举 |
| --- | --- |
| 资料状态 | `complete` / `metadata-only` / `missing-source` / `needs-review` |
| 页面成熟度 | `red` / `yellow` / `green` |

## 阅读路径

1. 先从专业索引找到专业。
2. 再进入课程页查看教材、来源、真题索引与学习计划。
3. 若页面为 `red/yellow`，以缺口雷达和 GitHub issue 为准补齐。
