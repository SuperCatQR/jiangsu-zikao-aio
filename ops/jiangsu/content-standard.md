# 江苏自考公开内容标准

## 课程页结构

每门课程页固定包含：

1. 基本信息：课程代码、课程名、学分、所属层次、考试期次。
2. 资料状态：教材、考纲、真题、官方计划、内部资料路径。
3. 学习目标：按章/模块列出可检查目标。
4. 阶段计划：入门、精读、刷题、冲刺、考前复盘。
5. 复习计划：30 天 / 14 天 / 7 天模板。
6. 练习与真题：只放公开题目链接或内部索引，不贴版权内容。
7. 来源与核验：A/B/C 分级、最后核验日期、缺口。

## Markdown 排版

- 一级标题只用课程名或专业名。
- 表格字段顺序固定：`项目 | 内容 | 来源 | 状态`。
- 日期用 `YYYY-MM-DD`。
- 课程代码保留前导 0。
- 内部路径写 `materials://...`，不得写 GitHub raw private URL。
- 不确定信息标 `待核验`，不得猜。

## 学习计划粒度

- 阶段目标用可验收动词：完成、整理、背诵、默写、刷完、订正。
- 每阶段给输入资料、输出物、完成标准。
- 周计划不超过 6 周；长周期用里程碑，不逐日铺满。

## 资料状态枚举

- `complete`：资料齐、已核验。
- `metadata-only`：只有元数据或内部路径。
- `missing-source`：缺官方/授权原件。
- `needs-review`：已入库但未人工核验。

## 双层内容标准与质量门禁

课程内容严格区分为**官方事实层**与 **AI 备考层**，分别由统一门禁系统的 `evidence` 与 `ai-content` 层校验：

### 1. 官方事实层（Official Facts Layer）—— `evidence` 门禁
- **载体**：`sources/jiangsu/courses/<code>/evidence.json` 与 `knowledge-model.json`。
- **事实状态**：每个事实只能是 `verified`（必附 provenance 凭证）或 `named_gap`（必附 gap_impact 与 next_evidence 缺口定义）。**非 `verified` 的事实不得携带 `value`** —— 未验证的值一旦渲染就会冒充官方事实（`evidence` 层失败关闭）。
- **准入控制（L1 Eligibility）**：只有考纲与教材官方凭证齐全的课程方可获评 `L1` 准入资格；非 L1 课程禁止生成或提交 `content.json`。
- **知识模型规范**：
  - 知识点必须按 `<code>-(intro|ch\d{2}|ap\d{2})-s\d+-p\d+` 统一规范编号，且全局唯一。
    （`ap\d{2}` 是**附录考核单元**的 slug，如 `02333-ap07-s1-p1` —— 附录与章共用同一套 unit 编址；
    附录是**独立考核单元**，不得把附录内容挂到章下。）
  - 原文摘录（quote）不得超过 60 个字符，防止整段抄袭考纲。
  - 知识点对考纲覆盖率必须达到 90% 以上，且 `diff_vs_manual` 中不得遗留 `manual_only` 缺口。
  - **章目判据与回退的触发条件（KB-2）**：章目**先**从考纲的 `大纲目录` 切片取（折叠空白后逐行匹配
    `导论` / `第N章 …`）；**只有当主判据失败时**（缺该切片、或切片内没有章标题行）才回退到
    `Ⅲ 课程内容与考核要求` 节推章目。**回退只在主判据失败时触发** —— 有目录页的课程
    （`15040` / `15043` / `15044`）在主判据上即成功返回，回退分支对其**不可达**，故其模型产物保持
    **逐字节不变**。回退自身失败关闭：找不到 `Ⅲ` 节、或该节之后没有章标题即报错，绝不无声产出空章目。
  - **章目与节号的连续性**（失败关闭，不发明章号/节号）：章序标签推出的章号必须严格递增、步长恒为 1，
    且首章只能是 `0`（导论类）或 `1`；源侧声明的节号必须都在 `sections[]` 或 `not_assessed` 留痕里现身。
    两者不满足时报错并**指名缺哪些章号 / 节号**，绝不静默丢弃。
- **80 字符块引用块界的适用边界**：`ai-content` 层的「`>` 引用块 ≤ 80 字符」界约束的是**引文**——考纲原文摘录、样卷题文等**可能构成整段转载**的文本；它**不**约束 `official_only` 页（`index.md` / `syllabus.md` / `sources.md`）上的**手写官方元数据说明**，那类文本改由更强的**字节保留不变量**约束（渲染器不得改写手写散文，只允许追加派生区块）。两半各由一个测试锁住：`tests/test_render_pages.py::test_no_blockquote_over_80_chars` 覆盖渲染器产出页（`plan.md` / `practice.md` / `review.md` / `knowledge/*.md`），`test_render_pages.py::test_official_page_prose_is_not_rewritten` 覆盖三张官方事实页。故 `syllabus.md:4` 的 145 字符手写引用块是**有意豁免**（plan F10 裁定維持現状），不是漏检；若将来要收紧为**全树**界，必须先把「引文」与「手写说明」两类文本区分开，再同步改上述测试的作用域说明。

### 2. AI 备考层（AI Prep Layer）—— `ai-content` 门禁
- **载体**：`sources/jiangsu/courses/<code>/content.json`。
- **四件套标注（Quad Annotation）**：每个考点讲解/记忆/练习块（`blocks[]`）、阶段学习计划（`stage_plan[]`，必须恰好 5 个阶段）以及考前排程（`review_schedule`）均必须标注：
  - `ai_generated: true`
  - `generator`: 含 backend, model, prompt_id, prompt_version, generated_at
  - `evidence_refs`: 引用考纲/教材事实的非空列表
  - `review_state`: `"machine_draft"`（未经人工核验前绝不标 reviewed/publishable）
- **题型与练习（Drill）**：题型必须在考纲声明的题型集合内；必须提供 `answer_md`；来源仅限 `ai_generated` 或带明确凭据的 `official_sample`。
- **防抄袭守卫**：AI 生成的自然语言（`blocks[]`、`stage_plan[]`、`review_schedule` 的缺口文案）与考纲抽取原文的
  8-gram 字符级重合率严格不得超过 20%。语料取自 `evidence.json` 的 `syllabus.path` 并校验其 `sha256`（缺失即失败关闭）。
  **已声明豁免**：`review_schedule.plans[].items[].focus` 是确定性派生标签（章序标签 + 考纲节标题逐字拼接，实测重合率 85%），
  不是 LLM 生成正文，故不在守卫作用域内；它只出现在 `review.md` 的排程表里，且该页带 AI 横幅。
- **AI 块页面到达性对账**：`ai-content` 层不只校验标注，还要证明每个 AI 产物块**真的落到了页面上**。对账口径是
  **4 个块类别（`explain` / `memorize` / `drill` / `exam_strategy`）+ 2 个课程级顶层产物（`stage_plan` / `review_schedule`）**，
  一个都不能漏：`explain` / `memorize` 按**逐考核点锚点**对账 —— 每个有块的 `point_id` 都要在章页上存在自己的
  `### 考点精讲：<point_id>` 小节，且该小节内有对应 H4 标题（`#### 要点梳理` / `#### 记忆辅助`）、
  **正文非空**、且该标题**是读者可见的**（既不在代码围栏内，也不在 HTML 注释内 —— **Y2**：注释剥离发生在
  标题扫描**之前**，故「注释包住标题」与「注释包住正文」两种对读者等价的形状同判为未到达）；
  错误文案点名缺失的 `point_id`。两者另保留全部章页内的
  `#### 要点梳理` / `#### 记忆辅助` 小节数**精确相等**作为**次级页级界限**（只数**可见行**：注释里的同名标题
  不计入，否则计数可被注释补平；章页是唯一写入点，故不退化成下界）——
  **注意计数不是主判据**：全局精确相等**同样**防不住 padding（删一个点的标题、再在别处补一条同名标题，计数依旧相等），
  只有逐 `point_id` 锚点才防得住丢块；`drill` 对账 `practice.md` 的小节数与考核点锚点；
  `stage_plan` 对账 `plan.md` 的五阶段名与各自 `done_when`；`exam_strategy` 必须落在 `plan.md` 的 `## 应试策略`
  区块**之内**；`review_schedule` 按状态分支校验：`named_gap` 时须落在 `review.md` 的 `## 命名缺口` 区块之内，否则校验三档排程标记在页面上出现（**M-2 更正**：非缺口分支是整页子串校验，不是区块内校验，原措辞过度承诺）。
  此外，课程**存在 `content.json` 而渲染页目录不存在**时**失败关闭**（不再静默跳过整门课）；
  反向亦然（**F-QC3-2 / X2 / Y1**）：**渲染页上已有带 AI 横幅的 AI 页面、而真值源不在**时同样报错 ——
  作用域键不得替自己关闸，否则删掉真值源就能让整层 AI 页面照常发布。作用域键因此取**源侧
  `sources/jiangsu/courses/<code>/` ∪ 产物侧 `content/jiangsu/courses/<code>/` 的课码并集**：
  「产物存在」蕴含「源存在」，缺源时报文点名缺失的目录（整目录缺失）或 `content.json`（单文件缺失）。
  既无 `content.json` 又无 AI 横幅页面的课程保持全绿（其余 16 门课的真实形态）。
  这一条覆盖的正是「AI 备考层从未被渲染」的整层丢失形态；变异证明见 `tests/test_ai_content_gate.py`。
  产物侧课码按 `^[0-9]{5}$` 设界（**R21**）：`build` 暂存目录（`.15043.promote.xxx`）在
  `mkdtemp` → `os.replace` 窗口内被中断时会残留，它不是课程，不得进入作用域键而产生噪声错误；
  真实形态（课码目录在、源侧缺失）不受影响，仍报错。
- **页面完整性：未闭合注释必须失败关闭（R20）**：页面上出现**未闭合**的 `<!--` 时，其后内容对读者
  全部不可见，而注释剥离只处理**成对**注释 —— 若不加这条守卫，谓词与计数会把被注释吞掉的标题继续当成
  「已渲染证据」，页面残缺而闸门全绿。判据是「未闭合注释**是否真的隐藏了读者可见内容**」（开记号之后
  还有非空行），因此不隐藏任何内容的形状不报错：开记号是全文最后一个非空行、或记号落在代码围栏内。
  变异证明见 `tests/test_ai_content_gate.py::test_unclosed_comment_hiding_content_fails_closed`
  与其对称控制 `test_unclosed_comment_that_hides_nothing_does_not_fire`。
- **新课程的可扩展性规则**（S-4：本规则在 `15043` 接入时写定；`15044` / `00898` / `02333` 是其后三次验证，
  其中 `02333` 额外验证了**附录单元**也走同一套对账）：
  上述到达性对账**不含任何课程专属常量**，因此新课程无需为它改闸门代码，只需满足：
  - **章页模式由 schema 派生**，不得在闸门里硬编码目录名 —— 章页选定走
    `course.schema.json` 的 `generated_page_markers.ai_pages` 里**含 `/` 的子目录模式**（当前为
    `knowledge/*.md`）；改 schema 即改口径，闸门代码不必动。
  - **考核单元 = 章 + 附录**：附录页与章页同目录、同锚点口径；**阅读 / 导航序**是「全部章 → 全部附录」
    （`02333` 的 `index.md` 先列 `01-ch01`…`14-ch14`，再以「附录知识精读」一节列 `01-ap01`…`07-ap07`），
    而**磁盘文件名**按 `NN-` 前缀与章交错（字典序为 `… 06-ch06.md, 07-ap07.md, 07-ch07.md, 08-ch08.md …`，
    即 `07-ap07.md` 落在 `06-ch06.md` 与 `07-ch07.md` 之间）——
    两个口径不同，对账只按逐 `point_id` 锚点进行、不依赖文件名序（21 个单元页全绿）。
  - **不要求 `intro` 章 / `导论`**：对账按逐 `point_id` 锚点进行，与章的数量、序数起点、有没有导论无关
    （`15043` 即无导论章，10 章 `01-ch01`…`10-ch10` 全绿）。新课程的章 slug / 章序只需在
    `knowledge-model.json` 里自洽。
  - **只需满足「每个有块的 `point_id` 在章页上有自己的 `### 考点精讲：<point_id>` 小节」**：
    `explain` / `memorize` 的 H4 标题（`#### 要点梳理` / `#### 记忆辅助`）是**渲染器与提示词常量**
    产出的契约字面量，新课程**不新增**同类标题、也不必改这层判定。
  - **标注与页面两侧同时成立**：新增课程的 `content.json` 必须让 4 个块类别 + 2 个课程级产物都在页面上
    可验证到达；`fixture` 回放键覆盖由 `tests/test_generate_content.py` 的按课用例守护
    （每门有 `content.json` 的课程都应满足 `call_plan(model)` 的每个 `payload_hash` 在录制文件里可解析）。
- **渲染页面横幅隔离**：
  - AI 辅助生成的页面（`plan.md`, `practice.md`, `review.md` 及 `knowledge/*.md`）必须呈现含 `本页由 AI 辅助生成` 的警示横幅
    （正文区域靠前位置，位于 frontmatter / 生成注释之后；`practice.md` 另需遵守 canonical H1 首行契约）。闸门按子串 `本页由 AI 辅助生成` 判定。
  - 官方事实页面（`index.md`, `sources.md`, `syllabus.md`）绝对禁止包含 AI 横幅。
  - 所有由脚本生成的页面必须包含 `<!-- generated by scripts/build-course-content.py; do not edit -->` 注释。
